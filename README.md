# Online-Book-Store

A full-stack online bookstore built with Node.js/Express and React/Vite.

## Tech Stack
- Backend: Node.js, Express, MongoDB/Mongoose
- Frontend: React, Vite
- Payments: KHQR integration

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Project Structure
- `backend/` — server, API routes, models, and services
- `frontend/` — React UI and client-side pages
